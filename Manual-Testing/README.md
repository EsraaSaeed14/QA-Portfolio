# Manual Testing – SauceDemo

## Project Overview

This project demonstrates manual testing practices using the SauceDemo e-commerce demo application.

**Application:** https://www.saucedemo.com/

**Testing Scope:**
- Login functionality
- Product listing
- Shopping cart
- Checkout workflow
- Negative and edge-case scenarios

## Test Deliverables

- Test scenarios and test cases
- Bug reports (if defects are identified)
- Test execution results

## Project Status

In Progress – Test cases are being prepared and will be executed against the demo application.

**Note:** This is an independent portfolio practice project, not a commercial client engagement.
